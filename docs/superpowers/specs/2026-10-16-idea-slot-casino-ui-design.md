# アイデアスロット v2「カジノ筐体UI」設計書

日付: 2026-10-16
前提: v1 設計書 `2026-10-16-idea-slot-design.md` の続き。v1 の語データ・抽選ロジック・保存の仕組みはそのまま使い、**画面と操作を作り直す**。
見た目の基準: `docs/superpowers/specs/mockups/casino-v6.html`（会話で合意した最終試作）。迷ったらこれに合わせる。

## 目的

ボタンを押すたびに語がかけ合わさる道具を、「つい何度も回したくなる」カジノのスロット筐体にする。アイデアを出す道具としての速さ（すぐ回せる・すぐ保存できる）は落とさない。

## 参考にしたもの

- ジャグラー（パチスロ）: 当たりで光る GOGO!ランプ → 「IDEA!」ボタン
- ラスベガスの古典スロット: クロームと金の筐体、右側のレバー、流れる電球の看板、コイン受け皿
- ポケモン金銀のゲームコーナー / ドラクエのカジノ: 金の段階塗りドット文字、赤い「7」
- Balatro: ポーカーチップのボタン、緑のフェルトとトランプのカード
- パチスロ全般: 回転灯、赤いLEDカウンター、流れる電光掲示板、光るストップボタン

## 画面構成（上から）

1. **筐体**（ドット絵。横200×縦180ピクセルの canvas を拡大表示）
2. **チップボタン列**: 全部STOP／手動・自動STOP／リール設定／音 ON・OFF／メニュー
3. **リール設定パネル**（緑フェルト。チップで開閉）
4. **語えらびパネル**（緑フェルト＋トランプ型カード。リール設定から開く）
5. **当たり帳**（緑フェルト。保存した組み合わせとメモ）
6. **履歴**（緑フェルト。折りたたみ。直近100件）

「メニュー」チップは v1 の画面（自分の語・除外した語・書き出し/読み込み）を開く。中身は v1 のまま、見た目だけフェルト調に揃える。

## 筐体の構成

| 部位 | 内容 |
|---|---|
| 背景 | ベガス柄のカーペット、床の影、左下にチップの山、右下にコイン |
| 頂上 | 回転灯（パトランプ）。当たり演出中だけ光って光線が左右に振れる |
| 看板 | 金枠の中に「IDEA SLOT」（5×7ドット文字、金5段階＋黒縁＋影）。時々光沢が横切る。両脇に赤い「7」。枠の電球が流れるように光る（回転中は速く、当たり中は虹色） |
| 左右の柱 | クロームの縦縞。電球が上から下へ流れる |
| LEDバー | 左「IDEAS」＝回した回数、右「HITS」＝当たり帳の件数（赤い7セグ風、消灯セグも薄く見える）。中央は電光掲示板（文字が右から左へ流れる） |
| リール窓 | クローム枠。窓は円筒に見えるよう上下を段階的に暗く。中段がペイライン（左右に赤い矢印）。上の帯にはリール番号札だけ |
| IDEA!ボタン | リール枠の下中央（下表） |
| 操作台 | 各リールの下に STOP/LOCK ボタン（クロームの台座つき） |
| コイン受け皿 | コインがたまる。停止時に少し、当たり時に大量に降ってくる |
| レバー | 筐体の右外。クロームの棒と赤い玉。押す（クリック・タップ）と下がって戻る |

## リール

- 枠の数は 2〜4（リール設定で変更）。窓の幅は枠の数で等分する
- 1つの窓に3段（上・中・下）。中段が結果。上下は前後の語を小さく薄く見せる
- 回転中は帯が下へ流れ、約120ms ごとに語が入れ替わる。止まると少し弾む
- 長い語は折り返す（中段は最大2行）。スマホ幅でも中段の文字は 12px 以上
- ロック中の窓は金と赤の二重の縁取り

## 操作

| 操作 | 入力 | 動き |
|---|---|---|
| 回す | レバー／スペースキー | ロックしていないリールが全部回り出す。全部ロック中なら掲示板で知らせて回さない。回転中は無視 |
| リールのボタン | クリック・タップ／数字キー 1〜4 | 回転中＝**STOP**（赤く光る）で止める。停止中＝**LOCK**（暗い金）で今の語をロック。ロック中＝**LOCKED**（明るい金）で解除 |
| 全部STOP | チップ | 回っているリールを全部止める |
| 自動STOP | チップで切替 | 回すと左から順に自動で止まる（600ms + 320ms×番号） |
| 当たり保存 | IDEA!ボタン／Enterキー | 下表 |
| 種類を選ぶ | リール設定 | 各リールの種類（全部ランダム／単語の小分類／動詞／ジャンル／タグ…）。変更するとロックしていなければすぐ振り直す |
| 語を指定して固定 | リール設定の「語をえらぶ」 | 全種類から検索（上位50件、種類名つき）、または自由入力＋Enter。「いま出ている語」も選べる。選ぶとそのリールはロックされる |
| 語を除外 | 回っていない窓の語をタップ | 小さなメニュー「この語を除外」「この枠だけ振り直す」（v1 と同じ） |

全部のリールが止まったとき、組み合わせを履歴に残し、IDEAS を1増やす。

### IDEA!ボタンの状態

| 状態 | 見た目 | 押したとき |
|---|---|---|
| 回転中 | 消灯 | 何もしない（低い音） |
| 全部停止・未保存 | ピンクで点滅、「IDEA!」と「PUSH!」が交互、左右に金の小ランプ | 当たり帳に保存して**当たり演出** |
| 保存済みの組み合わせ | 金で「SAVED」 | 保存しない。掲示板で「保存ずみ」 |
| 当たり演出中 | 虹色 | 何もしない |

**当たり演出**（約3.2秒）: 回転灯、看板と柱の電球が虹色で高速、サイレン2回、ファンファーレ、コインのシャワー（受け皿にたまる）、掲示板に「★★★ BIG IDEA!! ★★★ 〇〇×〇〇×〇〇 を当たり帳に保存」。演出のあと当たり帳の新しいカードのメモ欄にフォーカス（スクロールはしない）。

当たりはユーザーが決める。ランダムな大当たりは無い。

## 当たり帳

- v1 のお気に入りと同じもの（`slot.favorites`、`{combo, memo, savedAt}`）。☆ボタンは廃止して IDEA! に一本化
- カード1枚＝組み合わせ＋一言メモ欄（入力のたびに保存）。新しいものが上。直近の保存は金色
- 各カードに「枠に戻す」「削除」

| 回転中 | SPINNING ... STOPを押せ！ ... |
| 全部停止 | ♦ 〇〇 × 〇〇 × 〇〇 ♦ いいね！と思ったら IDEA! ボタン ♦ |

## 効果音（Web Audio で生成、音声ファイルなし）

レバー（低いノコギリ波＋ラチェット）、回転中のカチカチ、STOP、LOCK／UNLOCK、全部停止の小さなチャイム、当たり（サイレン＋ファンファーレ＋コインの音）、押せないときの低い音。音 ON/OFF は保存する。初期値 ON。最初の操作のあとに AudioContext を作る（ブラウザの自動再生制限のため）。

## 動きを減らす設定

`prefers-reduced-motion` のとき、または設定で「演出を減らす」にしたとき: 電球の流れ・光沢・回転灯・コインの粒を止め、リールの弾みをなくす。回転と停止の操作自体は同じ。

## 保存（v1 からの変更）

- `slot.settings` に `autoStop: boolean`、`sound: boolean`、`reduceMotion: boolean` を足す。v1 の `animate` は読み込み時に `reduceMotion = !animate` へ移す
- 回転回数 `slot.stats = {spins: number}` を足す（IDEAS 表示用）。書き出し・読み込みの対象に含める
- ロック状態は保存しない（再読み込みで解除）
- それ以外（履歴・当たり帳・自分の語・除外）は v1 と同じ

## 構成

- 筐体のドット絵は canvas 1枚。動かない部分は起動時に裏の canvas に一度描き、毎フレームそれを写してから動く部分（電球・光沢・回転灯・LED・IDEA!・レバー・コイン）を描く
- リールの文字・ボタン・掲示板は canvas の上に重ねた HTML（座標は 200×180 の論理座標から % で配置。1論理ピクセル＝CSS変数 `--u`）
- 文字フォント: DotGothic16（SIL Open Font License）をリポジトリに同梱し、ライセンス文も置く。読み込めないときは monospace
- ファイルの分け方の目安: 筐体の描画（`src/cabinet.js`）、効果音（`src/sound.js`）、回転・停止・ロック・保存の状態遷移（DOM に依存しない純粋なモジュールにしてテストする）、画面の組み立て（`src/app.js`）、パネル類（`src/screens.js`）
- 依存パッケージなし・ビルドなしは v1 と同じ

## スマホ

- 筐体は画面幅いっぱい（左右16px）。チップは折り返して並べる
- リールのボタンと IDEA!ボタンは指で押せる大きさ（目安 40px 以上の当たり判定。足りない場合はボタンの当たり判定だけ広げる）
- レバーはタップで引ける。スペースキー相当として筐体の下にも「SPIN」チップを出す

## 確認方法

- 状態遷移のテスト: 回転中の STOP、停止中の LOCK/解除、全部ロックで回せない、回転中は IDEA! 無効、保存済みは重複しない、自動STOPの停止順
- 保存のテスト: v1 の `animate` からの移行、`stats` の読み書きと書き出し/読み込み
- ブラウザ: 3枠で回す→各 STOP→LOCK→再度回す（ロックした枠が動かない）→IDEA! で当たり帳に入る→再読み込みで残る。2枠・4枠の表示。375px 幅で横スクロールなし・中段文字 12px 以上・ボタンが押せる。音 OFF で鳴らない。動きを減らす設定で電球が止まる。コンソールエラーなし

## やらないこと

- ランダムな大当たり、クレジットや賭けの仕組み
- 筐体の横の「台選び」（種類の選択はリール設定パネルで行う）
- 当たり帳の端末間同期（書き出し/読み込みで代用）
