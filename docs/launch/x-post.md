## 動画（自動で作る）

```
node tools/video.mjs
```

- `out/idea-slot-demo.mp4` ができる（1920×1080、30fps、H.264、約12秒、約8MB、音なし。X にそのまま上げられる）
- `?demo` の台本を、時計を止めて1コマずつ撮るので、PC が重くてもカクつかない。全体で1〜2分かかる
- 撮り終わると `out/check/` に確認用のコマを書き出す。`--encode-only` で撮り済みのコマから mp4 だけ作り直せる
- `out/` は git に入らない。残したい動画は別の場所にコピーしておく
- mp4 にまとめるとき、jsDelivr から mp4-muxer（5.1.5）を読むので、ネットにつながっている必要がある
- コインの飛び方などは毎回少し変わる。気に入らなければ撮り直す

## 録画の手順（手で撮る場合・10秒前後の動画）

デモ用の URL を開くと、決まった流れを自動で1回演じます。保存データには何も書きません。

- 1回だけ演じる: https://toyogame.github.io/idea-slot/?demo
- 繰り返し演じる（撮り直しやすい）: https://toyogame.github.io/idea-slot/?demo&loop

流れ（全部で約11秒）:
1. 1秒待つ
2. レバーが下がって回り出す
3. 3本が順に止まり「ドラゴン × 料理 × ローグライク」がそろう
4. IDEA! で当たり。電球が虹色に光り、コインが噴き出して受け皿に積もる
5. 指の印が受け皿をなぞり、コインを回収（右下の COIN が増える）

撮り方（Windows）:
1. ブラウザを横長の窓にする。目安は 1280×720 か 1920×1080
2. 筐体が画面いっぱいになるくらいに置く
3. `?demo&loop` を開き、Win + Shift + S → 「録画」で、筐体のまわりを範囲選択して録る
4. 2周目の頭から1周ぶん（約11秒）を残すと、きれいに始まって終わる

スマホ向けに縦長も撮るなら、ブラウザの開発者ツールで 390×844 にして同じように撮ります。
X の動画は、横長 16:9 か正方形が、タイムラインで大きく見えます。

## 投稿の計画（2026-10-21 作成。時刻はすべて日本時間）

### 考え方
- 日本の X は夜 21〜23時に反応が集まりやすく、昼休みが次点、週末は朝が早めに寄る（[timetopost.co](https://timetopost.co/best-time-to-post/twitter/japan/)）
- 反応は投稿から最初の1時間、特に最初の15分の返信で伸び方が決まる。**投稿してから1時間は返信できる時間を選ぶ**
- ゲーム制作の人は、平日は夜、休日は日中に作業している。ネタ出しの道具なので「今から作る」タイミングに届けたい
- 10/31（土）は東京ゲームダンジョン14 があり、インディーの話題で混む。本投稿はその前の平日に置き、当日の盛り上がりには乗らない

### 日程
| いつ | 何を | ねらい |
|---|---|---|
| 〜10/27（火） | 準備（下のチェック） | 測れる状態で出す |
| **10/28（水）21:00** | **本投稿**（案A＋動画） | 平日夜のいちばん人が多い時間。週末の制作前に知ってもらう |
