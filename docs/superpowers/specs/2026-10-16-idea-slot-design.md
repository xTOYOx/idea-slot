# アイデアスロット 設計書

日付: 2026-10-16

## 目的

ゲーム企画のアイデア出し用の道具。複数の「語」をランダムにかけ合わせて `〇〇×〇〇×〇〇` を出し、発想のきっかけにする。考えるのは使う人。アプリは刺激を出すことに徹する（AI生成などはしない）。

## 前提・制約

- 一人で使う道具。ログイン・サーバーなし
- ブラウザで動く静的サイト。PCとスマホの両方で使える
- 公開は GitHub Pages（パブリックリポジトリ `idea-slot`）
- 単語は日本語・数万語以上。無名な語・専門用語も含め、常に全語から出す

## 画面と操作

```
枠の数： [2] [3] [4]

[動物▼]      [ジャンル▼]     [見た目▼]     ← 枠ごとの種類
┌────────┐   ┌──────────┐   ┌──────┐
│ カワウソ │ × │ ローグライク │ × │ 8bit │    ← リール
└────────┘   └──────────┘   └──────┘
  HOLD          ─            ─            ← 枠ごとのホールド

          [ かけ合わせる！ ]
       ☆お気に入り   ✕この語を除外

履歴：カワウソ×ローグライク×8bit / …
```

- 枠の数は 2〜4
- 各枠の種類は、下表の大分類・小分類のどれか、または「全部ランダム」を選ぶ
- 「かけ合わせる」（スペースキーでも可）を押すと、ホールドしていない枠のリールが回り、左から順に止まる。演出は1秒弱。設定で演出を切って即時表示にできる
- 語をタップすると「この語を除外」「この枠だけ振り直す」を選べる
- ☆でお気に入りに保存する。各お気に入りに一言メモを書ける
- 履歴は直近100件
- 「自分の語」画面：種類を選んで語を追加する。除外した語の一覧から元に戻す
- 設定画面：データの書き出し・読み込み（JSONファイル）。PC⇔スマホの移行用
- スマホ縦画面では、リールを縦に並べる

## 枠に入れられる種類

| 大分類 | 小分類 | 出どころ |
|---|---|---|
| 単語 | 動物／植物／食べ物／人・職業／場所・建物／道具・乗り物／自然・天気／体／感情・状態／出来事／抽象概念／その他 | 日本語WordNet の名詞（約9万語）。上位語をたどって自動分類 |
| 動詞 | なし | 日本語WordNet の動詞 |
| ゲームジャンル | なし | Steam のジャンル・サブジャンルを参考にした日本語リスト（100前後） |
| タグ | 見た目／雰囲気・テーマ／仕組み | itch.io と Steam のタグを参考にした日本語リスト（300前後） |

同じ種類どうしのかけ合わせ（ジャンル×ジャンル）も可。同じ回では同じ語を重複させない。

## 構成

```
idea-slot/
  index.html        画面
  style.css
  app.js            抽選・リール演出・保存
  data/
    words.json      単語（小分類ごとの配列）
    verbs.json
    genres.json
    tags.json       （見た目／雰囲気・テーマ／仕組み）
  tools/
    build-words.*   WordNet → words.json / verbs.json 変換スクリプト
  raw/              WordNet 元データ（git管理外）
  LICENSE-DATA.md   WordNet の帰属表示
```

- フレームワーク・ビルド工程なし。素の HTML/CSS/JS
- 辞書データは事前に `tools/` のスクリプトで加工する。アプリは JSON を読むだけ
- data の JSON は、起動時に `fetch` で読む。ローカル確認は簡易サーバー経由（`file://` では fetch が動かないため）

## データの作り方（単語・動詞）

1. 日本語WordNet（NICT）の元データを `raw/` に置く
2. 名詞の各語について、上位語（hypernym）を根までたどる。途中で当たった英語WordNetの代表的な上位概念（animal, plant, food, person, location/structure, artifact, natural phenomenon, body part, feeling/state, event, abstraction）に応じて小分類を決める。どれにも当たらない語は「その他」
3. 同じ表記は1つにまとめる。記号だけの語や、1文字のひらがな・カタカナは除く
4. 動詞は分類せず、まとめて verbs.json にする
5. 出力の目安：words.json は数MB以内。超える場合は分割読み込みを検討する

## ジャンル・タグの作り方

- Steam・itch.io の公開タグ名を参考に、日本語名の一覧を手で作る（ゲームを想起しやすい表現にする）
- 各語は `{"ja": "ローグライク", "en": "Roguelike"}` の形で持つ。表示は日本語

## 保存（localStorage）

| キー | 内容 |
|---|---|
| `slot.settings` | 枠の数、各枠の種類、演出のオン・オフ |
| `slot.history` | 直近100件の組み合わせ |
| `slot.favorites` | お気に入り（組み合わせ・メモ・保存日時） |
| `slot.custom` | 自分で追加した語（種類ごと） |
| `slot.excluded` | 除外した語 |

- 保存の読み書きは try/catch で囲む。壊れていたら初期値で起動する
- 書き出しは上記をまとめた1つの JSON。読み込み時は上書き前に確認する

## エラー時の扱い

- データの読み込みに失敗したら、画面にメッセージと再読み込みボタンを出す
- 選んだ種類の語が除外などで0件なら、その枠に「語がありません」と出して回さない

## 確認方法

- 抽選：ホールドした枠が変わらないこと。除外した語が出ないこと。同じ回で重複しないこと
- 保存：再読み込み後も履歴・お気に入り・自分の語・除外が残ること。書き出した JSON を読み込んで元に戻ること
- スマホ幅（375px）で崩れないこと
- GitHub Pages の URL をスマホで開いて動くこと

## やらないこと

- AIによる企画案の生成
- 端末間の自動同期（書き出し・読み込みで代用）
- アカウント・共有機能
